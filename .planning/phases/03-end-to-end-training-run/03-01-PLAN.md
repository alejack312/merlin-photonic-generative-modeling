<task type="auto">
  <name>Task 1: Build generator/train.py's reusable pieces and smoke-test them</name>
  <files>generator/train.py, tests/test_train.py</files>
  <action>
Implement `generator/train.py`:

- `LATENT_DIM` imported from `generator.noise` (never re-hardcode 10 — Phase 2's own pitfall).
- `build_generator(input_size=LATENT_DIM, output_size=400) -> ML.QuantumLayer`: thin wrapper around `ML.QuantumLayer.simple(...)`. Exists so both `train.py` and tests construct the generator identically.
- `train_step(quantum_layer, optimizer, p_real, kernel_matrix, batch_size) -> float`: the owner-confirmed batch-averaging step (DESIGN_DECISIONS.md 2026-07-24) —
  `optimizer.zero_grad()`; `z = sample_latent(batch_size)`; `q_batch = quantum_layer(z)`; per-row `mmd2(p_real, q_batch[i], kernel_matrix)` stacked and `.mean()`'d into one loss; `loss.backward()`; `optimizer.step()`; return `loss.item()`. Do not average `q_batch` before calling `mmd2` — that is a different, rejected training objective (03-RESEARCH.md Open Question 1). Do not pass `shots=` to the forward call — default analytic output is required.
- `decreasing_trend_check(losses: list[float], tail_frac: float = 0.1) -> dict`: exactly the pattern from 03-RESEARCH.md's Code Examples — `scipy.stats.linregress` slope/p_value over all epochs, plus first-`tail_frac`-vs-last-`tail_frac` mean comparison (`relative_drop`), combined into `passed = bool(slope < 0 and relative_drop >= 0.10)`. Returns a dict with `slope`, `p_value`, `first_mean`, `last_mean`, `relative_drop`, `passed`.

Write `tests/test_train.py`:
- A smoke test: build `CENTERS = make_bin_centers()`, `X_train, _ = load_circles_data()`, `P_REAL = compute_p_real(X_train, CENTERS)`, `K = gaussian_kernel_matrix(CENTERS, sigma=0.1)`, `quantum_layer = build_generator()`, `optimizer = torch.optim.Adam(quantum_layer.parameters(), lr=0.01)` — all built once, matching Pattern 1 (build once, loop many). Run `train_step` for ~5 iterations at `batch_size=4` (small/cheap — this is a regression guard, not the real run). Assert no exception is raised and every returned loss is finite (`math.isfinite`).
- Unit tests for `decreasing_trend_check` against synthetic data (no QuantumLayer needed, fast): a monotonically decreasing list (e.g. `[10 - 0.1*i for i in range(100)]`) must return `passed=True`; a flat/constant list must return `passed=False`; a monotonically increasing list must return `passed=False` and `slope > 0`.
  </action>
