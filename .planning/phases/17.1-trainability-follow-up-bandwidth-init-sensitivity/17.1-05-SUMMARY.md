## Decisions Made

- **Baseline reference for "the sigma=0.1 row":** interpreted as Phase 17's original `phase17_curve_fit_summary.csv` row itself (which was computed at sigma=0.1), since the plan text names that CSV as "the baseline" in the same sentence. Every TRAIN-09 sigma value (including 0.1) is compared against that same fixed baseline row, not against a separate reference point within the TRAIN-09 dataset.
- **"Weakens" threshold:** a self-chosen, documented 50% drop in either the fitted decay rate `b` or the AIC margin (`poly_aic - exp_aic`) relative to the baseline counts as "weakens" (verdict still "exp" but materially weaker signature). This is not an external statistical convention — it's this script's own cutoff, stated explicitly in `MATERIAL_SHRINK_THRESHOLD` and the `classify_survival` docstring, since the plan asked for "material" shrinkage without specifying a number.
- **Plot y-axis choice:** fitted exp decay rate `b`, not an AIC-delta. Rationale (stated in the script's docstring): `b` directly shows whether the exp signature's actual decay strength is shrinking with sigma, independent of whether the verdict happens to cross the `AIC_DELTA_THRESHOLD=2.0` boundary — a verdict can flip to "inconclusive" while `b` is still large and barely changed (weight1's sigma=0.3/1.0 non-flip-driven-by-b-collapse case), or vice versa.
- **`bin_spacing` column formatting:** since bin spacing depends on `n` (not `sigma`), each TRAIN-09/TRAIN-10 summary row records the full semicolon-joined list of bin spacings across that cell's `n`-range (matching the existing `exp_params`/`poly_params` formatting convention in Phase 17's original summary CSV), rather than a single collapsed value.
