<objective>
Wire Plan 17.1-01's data-dependent init primitives into the actual sweep pipeline as a third, selectable `init_scheme` -- `"data_dependent"` -- alongside the existing `small_angle`/`uniform`. This is the last piece of plumbing TRAIN-10 needs before Plan 17.1-05 can run the real sweep; no new math is introduced here, only dispatch and CLI wiring, following 17.1-RESEARCH.md's explicit recommendation to special-case this scheme entirely inside `pooled_gradients_for_cell` (its thetas are deterministic given `(n, generator_scope)`, so they should be computed once per cell, not re-derived on every draw for no reason).

**Design decision, stated explicitly per this project's CLAUDE.md ("no silent unilateral design decisions"):** this project's `mixed`-scope circuit (`photonic_weight2_iqp_distribution`) has no independent weight-2-only parameter -- `thetas[i]`/`thetas[j]` are the SAME variables used both as qubit i/j's own weight-1 phase AND as the weight-2 CZ-like gate's input (folded with +pi/4 internally, not by the caller). Recio-Armengol et al.'s paper assumes an ansatz where two-qubit gates have their own free angle, which this circuit does not have. The chosen translation: for `mixed` + `data_dependent`, qubits `i,j` (the weight-2 pair) get the covariance-based `weight2_data_dependent_theta` value instead of their own per-qubit arcsin(sqrt(mean)) value; every OTHER qubit keeps the standard weight-1 rule. This most closely honors the paper's intent (parameters touching the two-qubit interaction get the covariance-based rule) given this circuit's actual single set of n knobs -- stated here, and to be restated in `docs/trainability-study.md` (Plan 17.1-06), so the owner can override it on review if it doesn't match their intent.

Purpose: makes `init_scheme="data_dependent"` a fully working, testable option throughout the pipeline.
Output: `trainability/sweep.py`, `gradient_variance_sweep.py` updated; `tests/test_sweep.py` extended to prove the new scheme's determinism and the mixed-scope override behavior.
</objective>
