<task type="auto">
  <name>Task 1: benchmark.py — held-out MMD² statistic with untrained and floor baselines</name>
  <files>benchmark.py</files>
  <action>
Create `benchmark.py` at the repo root, following `natural_order_train.py`'s style (plain script, `if __name__ == "__main__": main()`), post-hoc only — no training, `.eval()` + `torch.no_grad()` throughout.

Imports: `load_circles_data`, `compute_p_real` from `generator.data`; `gaussian_kernel_matrix`, `mmd2` from `generator.mmd`; `build_naturally_ordered_generator`, `natural_sorted_centers` from `generator.naturally_ordered_generator`; `sample_latent` from `generator.noise`; `ring_band_metrics` from `generator.visualize`; `csv`, `torch`.

Constants: `SIGMA = 0.1` (matches training bandwidth, for direct comparability with all Phase 4 numbers — state this choice in a comment), `CKPT = "results/phase4_natural_checkpoint.pt"`, `N_DRAWS = 20` (mirrors Phase 4's 20-draw ring_mass stability check).

Setup (once):
- `centers = natural_sorted_centers()`
- `X_train, X_test = load_circles_data()` — `X_test` is the held-out split, never included in `p_real` at training time
- `p_real_train = compute_p_real(X_train, centers)`
- `p_real_test = compute_p_real(X_test, centers)`
- `kernel_matrix = gaussian_kernel_matrix(centers, SIGMA)`

Trained generator: `build_naturally_ordered_generator()`, `.load_state_dict(torch.load(CKPT, map_location="cpu"))`, `.eval()`.
Untrained generator: a second, fresh `build_naturally_ordered_generator()` — do NOT call `load_state_dict` on it, so its parameters stay at their random init. `.eval()`.

For each of {trained, untrained}, under `torch.no_grad()`, loop `N_DRAWS` times: draw `z = sample_latent(1)`, `q = generator(z)[0]`, compute `mmd2(p_real_test, q, kernel_matrix).item()` and `ring_band_metrics(q, centers)` (`ring_mass`, `gap_mass`). Collect all three as lists, then compute mean/std (use `torch.tensor(list).mean()/.std()`) for each of mmd, ring_mass, gap_mass.

Floor baseline (deterministic, no generator, no loop): `mmd_floor = mmd2(p_real_train, p_real_test, kernel_matrix).item()`.

Print a clear summary block (variant, mmd mean±std, ring_mass mean±std, gap_mass mean±std) for trained and untrained, plus the single floor MMD² value.

Write `results/phase5_benchmark_metrics.csv` with header `variant,mmd_mean,mmd_std,ring_mass_mean,ring_mass_std,gap_mass_mean,gap_mass_std,n_draws,sigma` and three rows: `trained`, `untrained` (all fields populated), `floor` (`mmd_mean` = the floor value, `mmd_std` = 0, `ring_mass_mean`/`ring_mass_std`/`gap_mass_mean`/`gap_mass_std` = empty string since ring/gap metrics don't apply to a p_real-vs-p_real comparison, `n_draws` = 1).
  </action>
  <verify>Run `python benchmark.py` from the repo root. It must exit 0, print the trained/untrained/floor summary, and `results/phase5_benchmark_metrics.csv` must exist with exactly 3 data rows (trained, untrained, floor) plus the header.</verify>
  <done>results/phase5_benchmark_metrics.csv contains real, computed numbers (not placeholders): trained and untrained MMD² mean±std and ring_mass/gap_mass mean±std over 20 draws each, plus a single deterministic floor MMD² value. Trained MMD² mean is lower than untrained MMD² mean (sanity: training helped) — if it is not, do not silently fix by changing the script; report this in the plan's summary as an anomaly.</done>
