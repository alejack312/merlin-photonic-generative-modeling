<task type="auto">
  <name>Task 2: Implement deterministic bin-center grid (GEN-03)</name>
  <files>generator/bin_centers.py, tests/test_bin_centers.py</files>
  <action>
    Create `generator/bin_centers.py` with `make_bin_centers(side: int = 20, lo: float = -0.1, hi: float = 1.1, dtype: torch.dtype = torch.float32) -> torch.Tensor`, implementing the verified pattern from RESEARCH.md Pattern 1 exactly (uniform grid via `numpy.linspace`/`meshgrid`, converted to a `torch.Tensor`, no `torch.rand`/seeded RNG anywhere — determinism must come from the algorithm itself, not a fixed seed):

    ```python
    import numpy as np
    import torch

    def make_bin_centers(
        side: int = 20,
        lo: float = -0.1,
        hi: float = 1.1,
        dtype: torch.dtype = torch.float32,
    ) -> torch.Tensor:
        """K = side*side uniform grid centers over [lo, hi]^2. Deterministic, no RNG.

        Default side=20 (K=400) with lo/hi=-0.1/1.1 covers the circles dataset's
        min-max-normalized [0,1]^2 range plus 10% padding on each side (see
        RESEARCH.md: contains the ~0.00025 test-set overshoot from quickstart.py's
        train-derived normalization, and leaves margin around the outer ring, which
        touches x,y in {0,1}).
        """
        xs = np.linspace(lo, hi, side)
        ys = np.linspace(lo, hi, side)
        gx, gy = np.meshgrid(xs, ys, indexing="ij")
        centers = np.stack([gx.ravel(), gy.ravel()], axis=1)
        return torch.tensor(centers, dtype=dtype)
    ```

    Create `tests/test_bin_centers.py` asserting, at minimum:
    - `make_bin_centers().shape == (400, 2)` (default `side=20` → K=400, per GEN-03/CONTEXT.md's locked K≈400).
    - Two separate calls (`make_bin_centers()` invoked twice, no shared state) produce tensors that are exactly equal (`torch.equal`), proving determinism — not just "close," since there is no RNG source to justify tolerance.
    - The grid's min and max along both axes are `pytest.approx(-0.1)` and `pytest.approx(1.1)` respectively (confirms bounding-box coverage per the padding decision).
    - No NaN/Inf values (`torch.isfinite(centers).all()`).
  </action>
  <verify>`./venv/Scripts/python.exe -m pytest tests/test_bin_centers.py -v` — all tests pass.</verify>
