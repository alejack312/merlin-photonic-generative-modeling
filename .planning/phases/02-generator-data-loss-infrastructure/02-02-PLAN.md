  <name>Task 1: Implement latent noise sampling (GEN-02)</name>
  <files>generator/noise.py</files>
  <action>
    Create `generator/noise.py` exposing:

    ```python
    import math
    import torch
    import merlin as ML

    LATENT_DIM = 10  # == QuantumLayer.input_size; see input_size correction below

    def sample_latent(batch_size: int) -> torch.Tensor:
        """Sample a fresh batch of Gaussian latent vectors for the generator circuit.

        Uses merlin's own NormalLatent (mean=0.0, std=2*pi) rather than a
        hand-rolled torch.randn — this is MerLin's own PhotonicGenerator
        convention (see 02-RESEARCH.md "Don't Hand-Roll"), not a project-specific
        choice. std=2*pi (not [0,1]) is deliberate: quickstart.py's [0,1]
        min-max normalization was that script's own choice for its classifier
        input, not a MerLin requirement (angle_encoding_scale defaults to 1.0,
        i.e. no automatic rescaling).

        dim=10 (not 2): input_size directly determines QuantumLayer.simple's
        natural output width. input_size=2 yields a natural width of only 3,
        so output_size=400 (GEN-03/GEN-05's K) would be 397/400 zero-padded and
        permanently degenerate (verified during 02-RESEARCH.md; corrected in
        02-CONTEXT.md with explicit owner sign-off). input_size=10 is the
        smallest value whose natural width (462) exceeds K=400, making
        ModGrouping do real regrouping instead of zero-padding.
        """
        return ML.NormalLatent(dim=LATENT_DIM, mean=0.0, std=2 * math.pi).sample(batch_size)
    ```

    Match the exact `merlin.NormalLatent` signature (`dim`, `mean`, `std`, then `.sample(batch_size, *, device=None, dtype=None)` returning `(batch_size, dim)`) — confirmed directly against the installed venv's source, do not guess the parameter names.
  </action>
  <verify>`./venv/Scripts/python.exe -c "from generator.noise import sample_latent; z = sample_latent(5); print(z.shape, z.dtype)"` prints `torch.Size([5, 10]) torch.float32`.</verify>
  <done>`generator/noise.py` exists, exports `sample_latent(batch_size) -> Tensor(batch_size, 10)`, and a smoke-run confirms the correct shape/dtype.</done>
