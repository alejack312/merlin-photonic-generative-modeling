# Phase 19 Plan 03: BosonSampling.jl Weight-1 Dual-Rail Cross-Check Summary

**Independently-built BosonSampling.jl dual-rail weight-1 photonic IQP circuit reproduces the Python/Perceval reference distribution to TVD ~1e-16 at n=2 and n=3 (well under the 1e-6 tolerance), with the phase-shift-to-theta convention algebraically derived rather than assumed.**

## Performance

- **Duration:** ~30 min

## Accomplishments

- Built a dual-rail (2-modes-per-qubit) weight-1 IQP circuit in BosonSampling.jl's own idioms (`beam_splitter`, `phase_shift`, `UserDefinedInterferometer`), independently of Perceval's HWP/WP/PBS polarization circuit in `iqp_photonic_encoding.py`.
- Algebraically derived the single-mode phase parameter `phi = pi - 2*theta` (BosonSampling.jl's `phase_shift(phi)` primitive) needed to reproduce this repo's `P(bit=0)=cos(theta)^2, P(bit=1)=sin(theta)^2` closed-form marginal, from first principles (`H*D*H` matrix multiplication), not by assumption.
- Verified the n=1 convention against the closed-form marginal to `atol=1e-10` before trusting the multi-qubit comparison.
- Diffed the full n=2 and n=3 distributions against Python's reference CSVs (`results/julia_reference/weight1_n2.csv`, `weight1_n3.csv` from Plan 19-01): TVD = 2.36e-16 (n=2) and 3.04e-16 (n=3) — both exact, non-sampling computations agreeing to machine precision.
- Wrote `results/phase19_verify03_weight1_results.md` with a **GO** verdict for VERIFY-03's weight-1 leg, generated directly by the passing script run.

## Decisions Made

- **Phase-shift derivation:** For `H = beam_splitter(1/sqrt(2))` (confirmed from BosonSampling.jl's own source: `beam_splitter(t) = [[t,-r];[r,t]]`) and `D = diag(1, exp(i*phi))` (the `phase_shift(phi)` primitive embedded on the lower rail), the combined unitary `U = H*D*H` applied to the bit=0 input gives `P(upper)=sin^2(phi/2)`, `P(lower)=cos^2(phi/2)`. Requiring `P(bit=0)=cos(theta)^2` to match Python's WP-derived closed form yields `phi = pi - 2*theta`. This was derived by hand, confirmed with a standalone numeric scratch check, and re-confirmed inside the committed script's own n=1 assertion — never assumed to be the more "obvious" `phi=2*theta`.
- **Unified bit convention:** Chose to keep bit=0 mapped to the same physical mode (upper/first-of-pair) at both input encoding and output decoding, absorbing the derivation's phase offset into `phi(theta)` rather than introducing an input/output convention mismatch. This keeps the circuit's own encoding self-consistent and easier to defend/explain unaided.
- **Single commit for both tasks:** Both tasks build and verify the same script incrementally; since they were authored and verified together in one run (both assertions pass, results file correctly generated), they were committed as one atomic unit rather than artificially split into a task-1-only intermediate commit with no independent verification value.
