<objective>
Build the Forge model MPAIR-03 and MPAIR-04 require: a SEARCH over ancilla-block assignments for `K_n` that establishes the minimum number of ancilla blocks a pooled k-pair CP(alpha) circuit needs, with a strengthened non-vacuity guard and a recomputed bitwidth.

Searching for a minimum colouring is the constraint-satisfaction problem a SAT-backed model finder is actually for.

Output: `forge/pooled_ancilla_allocation.frg` (a NEW file alongside `forge/ancilla_mapping.frg`, never an in-place extension of it) and `results/phase22_forge_run_log.md`.

Write these predicates:
- `pairsAreKn` — every `Pair` atom satisfies `0 <= p.i`, `p.i < p.j`, `p.j < Config.n`; and no two distinct `Pair` atoms have the same `(i, j)`. Combined with an `exactly C(n,2) Pair` bound clause, this pins the atom set to exactly the edge set of `K_n`.
