Builders (all return pcvl circuits unless noted):
- `build_state_prep_circuit(n)` — 2n-mode prep, all-|+>
- `build_diagonal_layer_circuit(n, thetas)` — weight-1 diagonal phase layer, `len(thetas) == n`
- `build_conjugation_circuit(n)`, `build_readout_circuit(n)`
- `build_cp_insertion(n, i, j, alpha)` -> `(cp_circuit, ancilla_spec)`; `cp_circuit` is a local `Circuit(8)`
  (4 data ports 0..3 + 4 ancilla ports 4..7); `ancilla_spec` keys are the LOCAL indices 4..7 and
  expect photon count 0 (vacuum in, vacuum out) — never a `{P:V}` herald photon.
- `_build_weight2_cp_processor_no_postselect(n, i, j, thetas, alpha)` — the SINGLE-pair reference wiring
  this plan generalizes. Its exact shape: `total_modes = 2*n + 4`; `pcvl.Processor("SLOS", total_modes)`;
  `proc.add(0, build_state_prep_circuit(n))`; `proc.add(0, build_diagonal_layer_circuit(n, thetas_folded))`;
  `proc.add(mapping, cp_circuit)` with
  `mapping = {2*i:0, 2*i+1:1, 2*j:2, 2*j+1:3, 2*n:4, 2*n+1:5, 2*n+2:6, 2*n+3:7}`;
  then `proc.add(0, build_conjugation_circuit(n))`; `proc.add(0, build_readout_circuit(n))`.
  Theta folding: `theta = alpha/4.0`, added additively to `thetas[i]` AND `thetas[j]` on a COPY of the
  caller's list. NO `add_herald`, NO `set_postselection` anywhere.
- `_weight2_cp_input_state(n, ancilla_spec)` — builds the `pcvl.BasicState` input (all-`{P:H},0` on the
  2n data modes, plain `0` on every ancilla mode).
- `_decode_single_qubit_pair(state, k)` -> `'0'`, `'1'`, or `None` (out of computational subspace).

Filtering convention (from `photonic_cp_iqp_distribution`, lines 692-812) — three ordered checks:
  1. any ancilla output mode non-zero -> `postselect_failure_prob`
  2. else, qubit i's OR qubit j's own dual-rail pair decodes to `None` -> `postselect_failure_prob`
     (NOT residual — this is CP's own two-part post-selection condition; getting it wrong produced
     TVD ~0.3-0.4 during Phase 15)
  3. else, any remaining bystander qubit decodes to `None` -> `residual`
  Finally: `dist` and `residual` are both divided by `(1 - postselect_failure_prob)`.
  Returns `(dist, residual, postselect_failure_prob)`.

Reference / metric:
- `exact_qubit_iqp_distribution(n, thetas, pair_thetas=None)` -> `{bitstring: prob}`.
  `pair_thetas` is `{(i, j): theta_ij}` with `i < j`, a `Z_i*Z_j` generator coefficient.
  Bit convention: qubit 0 is the MOST-significant bit; `bitstring[k]` is qubit k, left to right.
- `total_variation_distance(dist_a, dist_b)` -> float.

Operator identity (docs/iqp-photonic-encoding.md, ARB-01/ARB-02): one CP(alpha) insertion on pair (i,j),
with `alpha/4` folded onto both qubits' single-qubit thetas, realizes `exp(i*(alpha/4)*Z_i*Z_j)` up to
global phase. So a pair carrying ONE insertion at alpha has `pair_theta = alpha/4`, and the same pair
carrying TWO sequential insertions at alpha has `pair_theta = alpha/2`.
