<feature>
  <name>Classically-easy baselines (uniform, product-of-marginals) and BMS anticoncentration parameter</name>
  <files>hardness/baselines.py, tests/test_baselines.py</files>
  <behavior>
    `uniform_baseline(n) -> dict[str, float]`: returns `{bitstring: 2**-n for bitstring in all
    2^n n-bit strings}` -- every key from `"0"*n` to `"1"*n`, all `n`-bit binary strings, matching
    this project's existing `'0'/'1'` bitstring alphabet (`fock_to_bitstring`'s convention, NOT
    `expected_joint_distribution`'s `'H'/'V'` alphabet).

    `product_of_marginals_baseline(reference_dist, n) -> dict[str, float]`: computes each qubit
    `k`'s marginal `P(bit_k = '1')` by summing `reference_dist`'s probability mass over every
    bitstring with `bits[k] == '1'` (reference_dist's keys may not cover all 2^n bitstrings if it
    came from a lossy/residual-bearing sweep -- sum only over present keys, do NOT assume
    `reference_dist` is fully normalized to 1.0 internally, since a caller may pass in a
    loss-affected `dist` whose mass sums to less than 1 after residual/herald-failure bucketing;
    the caller is responsible for passing an appropriately-normalized reference -- document this
    contract explicitly in the docstring). Returns the product distribution over all `2^n`
    bitstrings: `{bits: prod(marginal[k] if bits[k]=='1' else (1-marginal[k]) for k in range(n))
    for bits in all bitstrings}`.

    `anticoncentration_alpha(dist, n) -> float`: returns `(2**n) * sum(p**2 for p in
    dist.values())` -- BMS Theorem 4's own normalization (`Sigma p_x^2 <= alpha * 2^-n`), computed
    directly/exactly (per `18-CONTEXT.md`'s explicit lock: "computed directly/exactly from the
    full simulated distribution... not sampled/estimated").

    Cases (input -> expected output), all to be encoded as pytest tests:
    1. **uniform_baseline(n)** for n in {1,2,3,4}: exactly `2**n` keys, every value `== 2**-n`
       (exact, not approximate -- no floating-point accumulation involved), `sum(values()) == 1.0`
       to `atol=1e-12`.
    2. **anticoncentration_alpha on uniform_baseline(n)** for n in {1,2,3,4}: returns `1.0` to
       `atol=1e-9` -- the maximally-anticoncentrated reference case (BMS's own bound is tightest,
       alpha=1, exactly here).
    3. **anticoncentration_alpha on a delta/point-mass distribution** (`{"0"*n: 1.0}`) for n in
       {1,2,3}: returns `2**n` to `atol=1e-9` -- the maximally-concentrated case.
    4. **product_of_marginals_baseline hand-computed example** (n=2, a reference_dist with known,
       hand-picked probabilities, e.g. `{"00": 0.5, "01": 0.3, "10": 0.1, "11": 0.1}`): compute the
       expected marginals by hand (`P(bit_0='1') = 0.10+0.10 = 0.20`, `P(bit_1='1') = 0.30+0.10 =
       0.40`), derive the expected product-distribution values for all 4 bitstrings by hand
       (`P('00') = 0.8*0.6 = 0.48`, etc.), and assert the function's output matches every one of
       these 4 hand-computed values to `atol=1e-9`.
    5. **TVD wiring sanity check** (reusing `iqp_photonic_encoding.total_variation_distance`, not
       re-derived here): `total_variation_distance(uniform_baseline(n), uniform_baseline(n)) ==
       0.0`; `total_variation_distance(uniform_baseline(2), {"00": 1.0})` matches the
       hand-computable value `0.5 * (|0.25-1.0| + 3*|0.25-0.0|) = 0.75` to `atol=1e-9`.
  </behavior>
