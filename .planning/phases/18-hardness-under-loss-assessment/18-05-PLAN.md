Define the fixed η grid as a module constant, ~6-8 points, geometrically denser near η=1 (low

```python
ETA_GRID = [0.99, 0.95, 0.90, 0.80, 0.60, 0.35, 0.05]
```

(7 points; gaps widen as eta decreases -- 0.04, 0.05, 0.10, 0.20, 0.25, 0.30 -- deliberately denser
near eta=1 per CONTEXT.md's locked spacing requirement. Same grid used for both weight-1 and mixed
scopes, per CONTEXT.md's "keeps the two scopes directly comparable" lock.)

`sample_thetas(rng, n)`: draw `n` circuit parameters via `rng.uniform(0, 2*np.pi, size=n)`, i.e.
this phase's own generic "uniform" init convention (reusing the shape, not the code, of
`trainability.sweep.sample_thetas`'s `uniform` branch) -- state explicitly in this function's
docstring WHY: HARD-05/HARD-07 want the loss sweep's circuit instances to be generic/representative
draws (matching Phase 17's own "uniform" scope, the regime that produced its clean measured
signal), not a special-cased warm start -- this is a deliberate, stated scope decision for this
phase (Claude's Discretion per `18-CONTEXT.md`), not silently inherited.

`pooled_cell_for_neta(n, eta, scope, draw_start, draw_count, weight2_pair=(0, 1), seed_base=180814)`:
for each draw index in `range(draw_start, draw_start + draw_count)`:
  1. `draw_rng = trainability.rng.get_rng(seed_base, scope, n, draw)` (reuse this repo's existing
     deterministic RNG substream utility verbatim -- do not hand-roll a second one; note this
     reuse explicitly as a deliberate decision, since `hardness` importing from `trainability` is
     a cross-package reuse of a generic utility, not trainability-specific logic).
  2. `thetas = sample_thetas(draw_rng, n)`.
  3. Compute the LOSSLESS reference distribution once for this draw (`eta=1.0` case) using either
     `hardness.loss_model.photonic_iqp_distribution_lossy(n, thetas, eta=1.0)` (weight1) or
     `hardness.loss_model_weight2.photonic_weight2_iqp_distribution_lossy(n, i, j, thetas,
     eta=1.0)` (mixed) -- this is the SAME loss-model function used for every other eta, called
     with eta=1.0, not a separate "lossless" code path, so the eta=1.0 cell in the final CSV is
     provably consistent with every other row (not a special-cased baseline computed a different
     way).
  4. Derive `product_of_marginals_baseline(lossless_dist, n)` from that SAME draw's lossless
     reference ONCE (per `18-CONTEXT.md`'s explicit lock -- "computed once, from the lossless
     target distribution, not recomputed per eta") -- compute this INSIDE the per-draw loop (once
     per draw, before the eta loop below), not inside a per-eta loop.
  5. For the REQUESTED `eta` (this cell's actual eta, which may or may not be 1.0): compute the
     lossy distribution via the same loss-model function, then:
     - `tvd_to_lossless = total_variation_distance(lossy_dist, lossless_dist)` (reusing
       `iqp_photonic_encoding.total_variation_distance`).
     - `tvd_to_uniform = total_variation_distance(lossy_dist, uniform_baseline(n))`.
     - `tvd_to_product_marginals = total_variation_distance(lossy_dist,
       product_of_marginals_baseline_from_step_4)`.
     - `alpha = anticoncentration_alpha(lossy_dist, n)`.
     - mixed scope only: `herald_failure_prob`, `herald_success_rate = 1 - herald_failure_prob`.
  6. Accumulate all of the above across draws into per-quantity lists.
Return per-quantity `(mean, std)` pairs (numpy `mean`/`std` over the draw list) plus `n_draws` --
mirroring `trainability/stats.py::summarize_gradient_samples`'s shape (a dict of named summary
stats), but for this phase's own distinct quantity set. Add a `combine_pooled_cells(list_of_dicts)`
helper analogous to `gradient_variance_sweep.py`'s `combine_chunks` concatenation logic, so
draw-chunks computed in separate processes can be merged by re-averaging the per-draw raw values
(store raw per-draw values in a `.npy`-serializable array per quantity when chunking is used, same
shape as `trainability/sweep.py::pooled_gradients_for_cell`'s existing chunking contract -- reuse
that SHAPE, not that code, since the quantities themselves differ).

Import `total_variation_distance` from `iqp_photonic_encoding`; `uniform_baseline`,
`product_of_marginals_baseline`, `anticoncentration_alpha` from `hardness.baselines`;
`photonic_iqp_distribution_lossy` from `hardness.loss_model`;
`photonic_weight2_iqp_distribution_lossy` from `hardness.loss_model_weight2`.

  <action>
Create `loss_sweep.py` at the repo root, matching `gradient_variance_sweep.py`'s established CLI
shape as closely as possible (same flag names/semantics where the concepts overlap, so this
project's execution pattern stays consistent across phases):

```
python loss_sweep.py --scope weight1 --n-values 2 3 4 5 6 --n-draws 5 \
    --out results/phase18_weight1_loss_sweep.csv

python loss_sweep.py --scope mixed --n-values 5 --n-draws 5 \
    --out results/phase18_mixed_loss_sweep.csv \
    --draw-start 0 --draw-count 1
python loss_sweep.py --scope mixed --n-values 5 --n-draws 5 \
    --out results/phase18_mixed_loss_sweep.csv \
    --draw-start 1 --draw-count 1
... (5 chunks of 1 draw = 5 draws total) ...
python loss_sweep.py --scope mixed --n-values 5 --n-draws 5 \
    --out results/phase18_mixed_loss_sweep.csv --append --combine-chunks
```

Flags: `--scope {weight1,mixed}`, `--n-values` (nargs+, int), `--n-draws` (default 5 -- this
phase's own default draw count, deliberately lower than Phase 17's 100: TVD/alpha are
distribution-level exact quantities per draw, not noisy per-parameter gradient samples, so a
handful of draws is enough to check robustness across circuit instances, not hundreds), `--out`,
`--append`, `--draw-start`/`--draw-count` (chunk mode: computes one draw sub-range for ONE (n,
scope) cell across ALL eta values in `hardness.sweep.ETA_GRID` in that single invocation --
weight-2's expense is per-cell-per-eta, so chunking by draw range amortizes across the whole eta
grid in one process rather than needing a THIRD chunking dimension), `--combine-chunks` (loads
every `.npy` chunk for a given (scope, n), concatenates raw per-draw arrays, re-summarizes,
writes/appends the final CSV rows -- one row per (n, eta) pair). CSV columns: `n, generator_scope,
eta, n_draws, tvd_to_lossless_mean, tvd_to_lossless_std, tvd_to_uniform_mean, tvd_to_uniform_std,
tvd_to_product_marginals_mean, tvd_to_product_marginals_std, alpha_mean, alpha_std,
herald_failure_prob_mean, herald_failure_prob_std, herald_success_rate_mean` (the last three left
blank/NaN for `scope=weight1`, which has no herald).

Mirror `gradient_variance_sweep.py`'s exact `run()`/`run_chunk()`/`combine_chunks()` structure and
flush-after-every-row / `os.fsync` discipline (a crash mid-sweep loses at most the in-progress
cell, not every already-completed row).
