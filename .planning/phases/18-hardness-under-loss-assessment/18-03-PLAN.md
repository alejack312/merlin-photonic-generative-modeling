<objective>
Build the weight-2 loss-sweep core function -- `photonic_weight2_iqp_distribution_lossy(n, i, j, thetas, eta)` -- HARD-07's central primitive: physical photon loss compounded with `heralded_cz`'s own herald-failure probability, run through the real pipeline so the two failure modes interact as they physically would (18-CONTEXT.md's explicit, locked decision -- never an analytical multiplication of a separately-computed lossless 2/27 herald rate against a separately-computed loss-survival probability).

Same two `18-RESEARCH.md` gotchas as Plan 18-02 apply here and must be baked into this function's own tests, not assumed carried over from that plan:

1. **Pitfall 1** -- loss MUST be applied via `pcvl.LC` insertion into a `Processor`, never via `noise=NoiseModel(...)` (confirmed no-op for polarization-annotated circuits, which this weight-2 pipeline also is).
2. **Pitfall 2** -- `proc.min_detected_photons_filter(0)` must be called explicitly, or the automatic filter (blind to `LC` components) silently discards every lossy branch.

The weight-2-specific addition (HARD-07, per `18-CONTEXT.md`'s locked decision): `LC` loss is applied UNIFORMLY across all `2n+2` modes, including the 2 `heralded_cz` ancilla modes -- not just the `2n` data-carrying modes -- so the sweep can see whether loss degrades the herald mechanism itself, not only the post-herald data readout. The existing `residual`/`herald_failure_prob` bucketing convention `photonic_weight2_iqp_distribution` already uses generalizes correctly to loss with NO new decode logic needed (`fock_to_bitstring`/`_decode_single_qubit_pair` already return `None`, i.e. residual, for a `(0,0)` lost-photon mode pair) -- per `18-RESEARCH.md`'s explicit confirmation; this plan reuses that classification loop verbatim rather than re-deriving it.

Purpose: this is HARD-07's foundational primitive -- every weight-2 number in Plan 18-06's real sweep and Plans 18-07/18-08's write-up traces back to this function.
Output: `hardness/loss_model_weight2.py` (new module), with a passing TDD test suite proving both Perceval-mechanism pitfalls are avoided and the ancilla-inclusive, non-decomposed compounding behavior is real.
</objective>
