## Overview

Extend MerLin's quickstart circles-dataset classifier into an MMD-trained photonic generative model, benchmark it honestly, and publish it as a credential/portfolio piece before September 1, 2026. The path ran from a verified environment and architecture decision, through building the generator's data/loss infrastructure, to a critical end-to-end training checkpoint on July 25, then quality tuning, benchmarking, and finally packaging the result for Vincent Espitalier, a public repo, and a portfolio case study.

## Milestone Summary

**Key Decisions:**

- Extend quickstart classifier into an MMD generator (not reproduce a catalog paper directly) — reuses owner's MMD/generative-modeling background from the prior IQP-MMD project.
- Generator output = full-distribution/histogram matching via closed-form MMD² — avoids collapsing the circles' two-ring target into its empty middle, avoids non-differentiable discrete sampling.
- Batch-averaged per-sample MMD² training step (not batch=1) — noise reduction for a defensible decreasing-trend check under deadline pressure. Later found (post-hoc audit) to be an upper bound on the true marginal-distribution MMD², not an identical quantity — documented as a caveat, not reversed.
- Natural-order correspondence fix (K=462, radius-sorted bins, no ModGrouping fold) chosen over two rejected alternatives (increasing `input_size`, which was diagnosed as counterproductive; a naive continuous point-averaging fallback, rejected in Phase 1) — the project's single largest quality improvement, though its causal mechanism was later found to be asserted, not demonstrated (see below).
- Cross-repo portfolio case study (separate Next.js site) rather than a markdown file in this repo — matched the actual reference format the owner intended.

**Issues Resolved:**

- July 25 stall-risk checkpoint met a day early — the historical PennyLane stall pattern (stalled since May 2026) did not recur here.
- A self-directed v1 milestone audit (Codex/gpt-5.5 deep review, directed at MerLin's local package source and the sibling IQP-MMD project's Obsidian vault) found and the project fixed: a backwards tau/sigma direction claim in `docs/mmd-loss.md`, a misattributed statistic in `results/phase5_summary.md`, stale batch-sweep numbers that had drifted from an unseeded rerun, a factually wrong claim about the sibling project's exact-MMD path, a silent-mismatch footgun in `NaturallyOrderedGenerator`, and an unsupported "reproducible" claim.
- Windows-specific Next.js build failures during case-study work were diagnosed as disk-space exhaustion (C: drive at 100% capacity), not a code defect — documented as a cross-project learning note (`~/.claude/learnings/2026-07-29-windows-nextjs-build-disk-space.md`).

**Issues Deferred:**

- The private-repo visibility toggle remains the owner's manual step (`gh repo edit alejack312/merlin-photonic-generative-modeling --visibility public`) — the case study's "Source Code" link and the technical note both 404 until this happens.
- Sending the drafted technical note to Vincent Espitalier is the owner's manual step.

**Technical Debt Incurred (honestly caveated, not silently dropped):**

- GEN-07 not met — generated samples improve measurably (ring_mass 0.609→0.691) but do not form two recognizably distinct rings. This is the project's core honest result, not a bug.
- The natural-order-correspondence mechanism story (radius sorting → fewer fragments → easier for the circuit to fit) is asserted in `DESIGN_DECISIONS.md` but never directly tested — MMD's permutation-invariance means the claimed benefit only holds if the circuit's raw outputs independently have neighbor-locality, which was never measured. A concrete follow-up test is named in the case study's "What I'd Do Next."
- Sigma=0.1 was never re-swept after the correspondence fix changed the bin grid from K=400 to K=462 — a plausible confound for the ring_mass improvement, not yet ruled out.
- No RNG seeding anywhere in training or benchmarking — all reported improvements are from single runs, not confirmed reproducible across seeds.
- BMK-03 (exact apples-to-apples comparison against MerLin's photonic QGAN reproduction on a matched dataset) remains a stretch goal, out of scope for v1.
