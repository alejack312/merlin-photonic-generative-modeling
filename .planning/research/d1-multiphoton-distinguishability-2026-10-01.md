# D1 multiphoton distinguishability: evidence collected 2026-10-01

Read-only fact-finding; no model selection, recommendation, new simulation, or hardware experiment. The sources below distinguish **M_s**, overlap between desired single photons, from **M_sn**, overlap between signal and unwanted noise photons. A reported source indistinguishability is not automatically M_sn. PDF pages are one-based; printed page numbers are given where useful. Confidence describes whether the claim is explicit or requires the stated inference, not independent replication.

## Not found / could not verify

- **A universal answer for current Quandela hardware:** not established. The 2021 source-specific fits show near-zero laser-noise overlap and low but nonzero fitted overlap for re-excitation; they do not establish a universal value for a pulse's second photon in Ascella, Belenos, or every product source. Excitation scheme and contamination mechanism differ across the inspected publications. No model is selected here.
- **Direct same-pulse g2-pair overlap calibration for named Ascella or Belenos hardware:** none found. The reported desired-photon M_s/HOM values cannot fill this gap. The Ascella cited-model chain above is positive evidence of a published simulation assumption, with the inference boundary stated explicitly.
- **An exact physical separable state for re-excitation:** not established by the fitted phenomenological model. Ollivier et al. explicitly discuss time correlations and an approximate separable treatment. Neither the software default nor the binary flags prove zero physical overlap.
- **Independent continuous unwanted-photon overlap in Perceval's Python Source constructor:** not found in the inspected v1.2.1/v1.2.4 signatures. The underlying native implementation was not audited beyond the wrapper call/property shown above.
- **A notebook/paper comparison of both Perceval flag settings with the same tomography calibration and numerical output:** none found. The documented trion fits and analytical limits above provide comparisons of physical correction models, not such a Perceval benchmark. The 0.7.3 migration also changes other source conventions, so its discussion is not an isolated A/B benchmark.
- **Belenos supplementary material:** the inspected arXiv main PDF refers to supplementary information, but the linked arXiv record provides a 12-page main PDF; a separate supplement was not located/read in this bounded search. No claim is made about what an unavailable supplement contains.
- **Paywall/access accounting:** the substantive PRL/PRX PDFs, GHZ arXiv PDF, Ascella supplement, Nature Communications main article, Belenos main paper, versioned Python source files, and official Perceval pages were read. No paywalled text is used as read evidence. The fibre-pigtailed article's PMC mirror was inaccessible, but its publisher text was read.
