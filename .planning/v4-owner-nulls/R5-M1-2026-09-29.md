Explanation:

- IQP gates commute, so the gate ancillas can be measured in any order.
- Structure: one ancilla per generator; ancilla j is wired to the data qubits in its row.
  Example n=3: anc1 touches data 1,2; anc2 touches data 2,3. Per data qubit:
  data1 <- anc1; data2 <- anc1, anc2; data3 <- anc2.
- Output bit i flips iff the XOR of the outcomes of the ancillas wired to it is 1.
  Examples: s=(0,1) flips bits 2,3; s=(1,0) flips bits 1,2; s=(1,1) flips bits 1,3
  (data 2 sees 1 xor 1 = 0).

Null (M1 equality): The corrected output x = y xor G^T s has the same distribution as
q\_theta(x), because the raw data outcome y follows q\_theta shifted by G^T s and the XOR
by G^T s shifts it back. Compared with the IQP distribution, the difference should be
zero (<= 1e-12), and anything else means the code's computation is wrong.
Expected result = equality: matching is a code check, not a finding, and not evidence
that adaptivity helps.

Corruption fixture: the negative control must use a target distribution that is NOT
invariant under the flips the corruption applies. Owner choice: a distribution
concentrated on a single outcome (e.g. all mass on 000), where a wrong XOR (e.g. flipping
bit 1 only, or all bits) moves the mass. A uniform target would hide the corruption;
include it only as a documented "corruption invisible" control.
