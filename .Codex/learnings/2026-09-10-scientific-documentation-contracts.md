Date: 2026-09-10 · Scope: project · Recurs when: a release follows corrected scientific claims.

## Context and constraints
- Preserve measured artifacts and owner-authored history; change current claims explicitly.
- Bounded implementation acceptance is separate from the original scientific scope.

## Approach
1. Inventory current reports, historical plans and owner records separately.
2. Match each active claim to code, committed evidence or a primary source.
3. Check theorem assumptions and notation before transferring a result.
4. Probe equations independently and validate local links before committing.

## Decision rules
- If bandwidth notation differs, translate the exponent before comparing scaling.
- If a kernel is finite, distinguish a dense Walsh representation from an efficient diagonal estimator.
- If probabilities are subnormalized, separate accepted mass, conditional quality and failure outcomes.
- If optical input and output rail conventions differ, document both; never infer one from the other.
- If an owner annotation is incorrect, add a dated correction without rewriting their words.
- If a report is historical, link current conclusions prominently and preserve its provenance.

## Pitfalls
- A real-versus-real empirical MMD value is not a mathematical floor.
- Separate toolchains can share an incorrect mathematical assumption.
- Low conditional discrepancy does not imply good target fit or practical sampling cost.
